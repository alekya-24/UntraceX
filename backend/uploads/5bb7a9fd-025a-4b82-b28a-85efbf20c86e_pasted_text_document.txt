BUILD A SIMPLE FULL-STACK WEBSITE CALLED “UNTRACEX”

UntraceX is a document inspection and cleaning application.

The main purpose is:

UPLOAD DOCUMENT
↓
DETECT AI-RELATED WRITING INDICATORS
↓
SHOW AI-GENERATED / HUMAN-LIKE ESTIMATE
↓
HIGHLIGHT DETECTED AI-RELATED TEXT PATTERNS
↓
DETECT DOCUMENT METADATA
↓
HIGHLIGHT METADATA INFORMATION
↓
USER SELECTS WHAT TO REMOVE
↓
REMOVE SUPPORTED INFORMATION
↓
COMPARE BEFORE VS AFTER
↓
DOWNLOAD CLEANED DOCUMENT

Keep the application simple, clean and professional.

Do NOT create a complicated enterprise dashboard.

==================================================
7. AI CONTENT RESULT
==================================================

At the very top:

AI CONTENT ANALYSIS

Show:

ESTIMATED AI-GENERATED CONTENT

                 XX%

and:

HUMAN-LIKE CONTENT

                 XX%

Example:

AI-GENERATED
78%

HUMAN-LIKE
22%

The percentage must be generated from the actual analysis.

Do NOT hard-code 78%.

Use labels:

LOW
MODERATE
ELEVATED

Example:

78%

ELEVATED AI-RELATED INDICATORS

Add a small explanation:

“This is an analytical estimate based on linguistic characteristics.
It is not definitive proof of AI authorship.”

Do NOT claim:

“This document is definitely AI-generated.”

==================================================
8. AI-RELATED TEXT HIGHLIGHTING
==================================================

THIS IS ONE OF THE MOST IMPORTANT FEATURES.

Show the actual extracted text.

Example:

-------------------------------------

DOCUMENT CONTENT

Python is a high-level programming language
that is widely used for software development.
It provides a simple and readable syntax and
supports multiple programming paradigms.

-------------------------------------

If the analysis identifies sentences or phrases
with stronger AI-associated linguistic patterns,
highlight those portions in RED.

Example:

Python is a high-level programming language
that is widely used for software development.

The highlighted section should be clearly visible.

Use:

RED = AI-related writing indicator

YELLOW = possible / moderate indicator

NORMAL = no significant indicator detected

Do NOT highlight random text.

The highlights must come from the actual analysis results.

20. BACKEND PROCESS
==================================================

When a file is uploaded:

STEP 1
Store the file.

STEP 2
Extract its text.

STEP 3
Extract supported metadata.

STEP 4
Analyze the extracted text for AI-related linguistic indicators.

STEP 5
Calculate an estimated AI-related likelihood.

STEP 6
Identify text sections associated with the detected indicators.

STEP 7
Return the text with highlight positions.

STEP 8
Display metadata.

STEP 9
Allow user to select removable metadata.

STEP 10
Create cleaned document.

STEP 11
Compare before and after.

STEP 12
Allow download.

==================================================
23. IMPORTANT LIMITATIONS
==================================================

The application must clearly distinguish between:

AI-related linguistic indicators

and

actual proof of AI authorship.

The system cannot determine with certainty whether a human or AI
wrote a document based only on text patterns.

Similarly, “metadata removal” only applies to metadata that the
application actually supports and can modify.

Never claim:

“Everything hidden has been removed.”

Instead say:

“Supported metadata removed successfully.”
